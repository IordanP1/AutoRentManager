# AutoRent Manager

AutoRent Manager is an ASP.NET Core MVC web application for managing car rentals and online reservations.

## Features

- Browse and search available cars
- View car details and rental prices
- Create reservations for selected dates
- Check car availability
- Manage cars, categories, and reservations as an administrator

## Getting Started

1. Clone the repository.
2. Open `AutoRentManager.slnx` in Visual Studio.
3. Configure the SQL Server connection string in `appsettings.json` or user secrets.
4. Apply the Entity Framework Core migrations.
5. Run the application from Visual Studio.
